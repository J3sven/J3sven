# J3 — Sven  

Hey there! 👋 I'm Sven, but online I go by J3. I'm a passionate software developer from The Netherlands, coding since 2012 and always eager to explore new technologies.  

Since 2023, I've been developing web players for video and audio at NPO, focusing on building high-performance, accessible, and scalable media experiences.  

In my spare time I love working on mods for games I enjoy playing. I am heavily involved in the RuneScape client & plugin development scene,
 contributing to HDOS as well as building plugins for the official RuneScape Plugin API.

NPO is my full-time employer. At NPO I am part of the player team where we develop media players. My focus is on the video and audio players for the various NPO platforms on the web including [NPO Start](https://npo.nl/start) and [NPO Luister](https://npo.nl/luister) as well as the websites for the NPO Radio channels and independent broadcasters under the NPO Umbrella.

](https://hdos.dev/)

In my spare time I do volunteer work on the HDOS OldSchool RuneScape client project. This project is aimed at re-creating the 2008-2011 era RuneScape HD look for OldSchool RuneScape through a reverse engineered client dating back to 2009. On the project my primary focus is porting over RuneLite plugins and making them compatible with our client. Though I have also delivered core client features and contributed art assets and tooling that boosts our artist productivity.

[<img width="500" height="86" alt="prettyRS-logo-small (1)" src="https://github.com/user-attachments/assets/127ff103-5edd-437e-8e6d-c723ec6497ed" />](https://github.com/PrettyRS)

PrettyRS is a github organization I have started to make it easier to manage contributions from collaborators on my RuneScape API Plugins, most notably [PrettyUI](https://github.com/PrettyRS/prettyui) and [Tilemarkers](https://github.com/PrettyRS/tilemarkers). For RuneScape I am part of the API Council, which is a select group of developers that help jagex shape future API developments and serve as mentors for the broader developer community. Through PrettyRS I hope to encourage collaboration and lay strong fundamentals of an open source attitude to RuneScape plugin development.
